# port_scanner
Educational multithreaded TCP port scanner in Python — demonstrates sockets, threading, and queues. For learning only. Do not scan without permission.

**Author:** Janhavi Mohite  
**Language:** Python 3  
**Purpose:** Educational project demonstrating sockets, threading, and queues for scanning TCP ports.

## 🔍 What this does
This project scans a range of TCP ports on a target IP and reports which ports are open. It uses multithreading and a queue to speed up scanning.

## ⚠️ Ethical & Legal notice
**Only scan machines you own or have explicit permission to scan.** Unauthorized scanning can be illegal and may be considered an attack.

## Features
- Multithreaded scanning using `threading` and `queue`
- Adjustable port range and thread count
- Simple, readable code for learning

## Prerequisites
- Python 3.7+ (no external libraries required)
